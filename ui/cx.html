    Fleet runs

    One active test across many equipment in one window - every terminal unit overnight. Each unit is its own active run with every safeguard above; the fleet adds a per-system concurrency limit (a system is the equipment that feeds it), a stagger, and an automatic stop once enough units fail. Confirm by typing the plan's code.

    PlannedTestStatusMembersFailures

    Scheduled retests

    Repeat a fleet run, e.g. every season. A schedule names its equipment, test, limits and windows; nothing runs until an admin approves exactly that by typing its approval code, and each window still runs only if active tests are switched on for this deployment at the time. Once approved a schedule can only narrow. Revoking it stops it, and any run it has going.
